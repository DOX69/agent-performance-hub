# Gemini 3.1 Capabilities

## Overview
Gemini 3.1 Flash introduces a 2M Context Window, allowing you to load entire codebases into context without chunking.

## Core Capabilities
- 2M Token limit
- Improved JSON mode

## How to Use
Pass your entire repository into the prompt using file concatenation scripts.
